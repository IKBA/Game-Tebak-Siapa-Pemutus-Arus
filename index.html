Panduan Teori Rangkaian Listrik DC (Kelas 12)

1. Rangkaian Seri (Pemutus Tunggal)

Pada rangkaian seri, semua beban (lampu hias) dihubungkan berurutan dalam satu jalur tunggal.

  • Arus: Itotal = I1 = I2 = I3 = ...
  • Tegangan: Vtotal = V1 + V2 + V3 + ...
  • Hambatan: Req = R1 + R2 + R3 + ...
🔑 Prinsip Pemutus Arus: Jika satu saja lampu dilepas atau putus, rangkaian menjadi TERBUKA (Open Circuit). Arus listrik langsung terhenti total (I = 0), sehingga SELURUH lampu padam.

2. Rangkaian Paralel (Jalur Independen)

Pada rangkaian paralel, tiap lampu memiliki cabang tersendiri yang terhubung langsung ke sumber tegangan.

  • Tegangan: Vtotal = V1 = V2 = V3 = ...
  • Arus Total: Itotal = I1 + I2 + I3 + ... (Hukum I Kirchhoff)
  • Hambatan Ekuivalen: 1/Req = 1/R1 + 1/R2 + 1/R3
🔑 Prinsip Pemutus Arus: Melepas lampu pada salah satu cabang hanya menghentikan arus di cabang itu. Cabang lain TETAP MENYALA karena masih memiliki lup tertutup ke baterai!

3. Rangkaian Campuran (Lampu Hias Dekoratif)

Rangkaian campuran menggabungkan bagian Seri dan Paralel.

Lampu yang dipasang pada Jalur Utama (Main Branch) sebelum percabangan bertindak sebagai "Master Cutout" / Pemutus Utama.

Sementara lampu yang berada di dalam percabangan hanya bertindak sebagai Pemutus Lokal Cabang.
